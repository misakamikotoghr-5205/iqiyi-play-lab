# 真实应用截图采集清单

这里目前只放采集说明，不放设计图假扮截图，也不放空白占位 PNG。由主线程操作共享浏览器采集；素材制作智能体不操作共享浏览器。

从项目根运行 `npm run dev`（已有构建会服务 `dist/`），默认 `http://127.0.0.1:4177`。建议390×844竖屏或实际手机尺寸。使用虚构演示进度；需要重来时使用应用自己的重置按钮，不通过改DOM、注入分数或伪造 localStorage 构造画面。只截应用内容，避开账号、个人信息、浏览器其他标签页与桌面。

| 应用 / 页面 | 至少一张实际交互画面 | 建议文件名 |
| --- | --- | --- |
| `http://127.0.0.1:4177/apps/rain-alley/index.html` | 用界面走访钟表铺、把线索记入手记；截走访记录或“调查手记 + 已取得证据”。首页可另拍，不能只用封面设计代替。 | `rain-alley-actual.png` |
| `http://127.0.0.1:4177/apps/cat-dispatch/index.html` | 第一关棋盘，选择一只猫并合法移动一步，截猫、花坛、终点、步数与撤回/提示控件。 | `cat-dispatch-actual.png` |
| `http://127.0.0.1:4177/apps/frame-director/index.html` | 选择一个剧本，移动或交换镜头，连续试映后暂停，截监视器与真实剪辑顺序；可另拍实际叙事反馈。 | `frame-director-actual.png` |
| `http://127.0.0.1:4177/apps/echo-rhythm/index.html` | 保持声音关闭，选“屋顶漫步”并开始，真实轻敲几次后暂停；截光轨、得分和暂停状态。校准面板可另拍。 | `echo-rhythm-actual.png` |

保存原始 PNG 到本目录。保留每张的页面、视口、实际操作与采集时间记录；如果截图只反映初始画面就如实标“初始界面”，不要命名为通关或成功结果。截图裁剪或压缩如由后台要求，应保留原图，不能替换文字或游戏状态。

文件到位后，素材检查可运行：

```sh
python3 submission/verify-materials.py --require-screenshots --out submission/package-audit.json
```

检查脚本只验证文件可解码、包与封面一致性，不能自动证明截图真实；需操作者本人确认来源。官方v11手册明确要求封面，未把这些建议截图描述为已核验的后台必填字段。
