# 四款独立小应用 — 爱奇艺投稿文案草稿

Prepared 2026-11-06. 四款需分别发布、分别勾选活动；本稿不是已发布或通过审核的记录。

## 共用的真实说明

四款为机制不同的原创竖屏离线互动应用。纯前端 HTML/CSS/JavaScript，不请求外网、不含外链、不需要账号。故事、关卡、镜头文本和谱面原创；画面使用 CSS、文本与系统字体，声音由 WebAudio 即时合成。开发使用 Codex 多智能体协作辅助编程，未使用或声称使用纳逗 Pro。源码 MIT，无第三方影视 IP。

实际上传包为 `dist/submissions/` 下四个独立 ZIP，各自根目录含 `index.html`，不能上传合集代替四款。录屏和截图从实际应用取得；不要把项目仓库或赛事链接放入应用包。

| 发布名称 | 简介候选 | 对应 ZIP |
| --- | --- | --- |
| 雨巷来信 | 用六个时段走访五处地点，记录独立证据，拼起雨巷里的误会。你的调查顺序与证据组合会走向不同结局。 | `rain-alley.zip` |
| 猫咪调度站 | 在四张棋盘为猫咪安排回家路线，避开障碍、互相让路。支持撤回与最短路径提示，挑战更少步数。 | `cat-dispatch.zip` |
| 24帧导演 | 调整原创短篇的镜头次序，体验顺叙、倒叙、平行剪辑与因果喜剧，连续试映后查看叙事反馈。 | `frame-director.zip` |
| 回声节拍 | 跟随三份原创程序谱面，用声音或纯视觉模式演奏；支持节奏校准、暂停、连击与评级。 | `echo-rhythm.zip` |

## 发布核对

按当前[官方 v11 使用手册](https://aic.iqiyi.com/activity/campaign/assets/interactive-app-guide-v11.pdf)，发布前须完成实名认证，通过[爱奇艺号创作者后台](https://creator.iqiyi.com/)“互动小应用 → 去发布”进入。若账号没有入口，须向运营确认当前权限；旧手册提到白名单，不代表当前所有账号都必须另行申请。本稿不代联系。

上传每一份 ZIP，填写账号当前要求的标题、简介、封面、分类与版权/AI 声明，并勾选[玩点新花样—AI互动小应用征集赛](https://aic.iqiyi.com/activity/ai-contest-2026)。后台完整字段以登录后的实际表单为准，未见表单的字段不标为已核实必填。提交成功后在“内容管理 → 互动小应用”跟踪审核，不能把待审记为上线。

至少四款原创小应用在截止前提交、审核通过并上线才满足现金奖相关数量门槛。尽早给审核与真机修正留时间。公开原型预览和 GitHub 推送均不计为平台上线。不得选择 IP 创作方向冒充使用了授权 IP；当前四款属于原创内容。

在平台手机 WebView 实测触控、存档、切后台暂停和音频延迟。当前本地测试不代替平台真机审核。
