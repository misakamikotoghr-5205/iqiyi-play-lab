## 运行与验证

需要 Node.js 22 或更新版本。运行时不需要 Node；它只用于验证、打包和可选预览。

```sh
npm test
npm run check
npm run build
npm run dev
```

默认预览地址是 `http://127.0.0.1:4177`，可通过 `PORT` 修改。也可直接打开四个 app 目录中的 `index.html`。开发服务优先提供已构建 `dist`，改动后请重新运行 build。

`npm run build` 使用内置 Node API 生成静态合集 `dist/` 和以下四份确定性 ZIP，无安装步骤：

- `dist/submissions/rain-alley.zip`
- `dist/submissions/cat-dispatch.zip`
- `dist/submissions/frame-director.zip`
- `dist/submissions/echo-rhythm.zip`

每份 ZIP 都把该款自己的 `index.html`、CSS、logic.js、app.js 与 MIT 许可放在根目录，不嵌套合集目录。构建会检查每包小于 20 MiB，并生成带字节大小、内容列表和 SHA-256 的 `dist/submissions/manifest.json`。正式投稿选择这四个独立 ZIP，**不要把整个合集打成一个应用上传**。

## 验证范围

行为测试验证故事分支与时间预算、四关实际可解与最优步数、非法移动与撤回、多个有效镜头序列、节拍边界判定/漏拍/空敲/结束。静态检查验证四款源码没有远程资源、网络 API、ES module、丢失或逃逸的本地资产，以及 JavaScript 语法和体积。手动浏览器与设备验证记录见项目交付说明；自动测试不代替活动后台真机审核。

## 原创与素材

故事、角色、谜题、关卡、镜头文字、图形排版和节拍谱均为本项目原创。画面由 CSS、文本符号和系统字体绘制；音频为 WebAudio 振荡器即时合成。无第三方 IP、下载素材或外部跟踪器。源码采用 MIT 许可。

已比较 Bemuse、StepMania、Twine 与 Shove 的 README、许可和固定提交，承认这些玩法与校准已有成熟实现。本轮独立实现 Echo 的十二拍离线校准、异常敲击剔除、稳定性门槛、可保存的正负判定偏移及统一漏拍/结束边界；没有复制外部代码或素材。具体差异、许可边界和验证见 [docs/landscape.md](docs/landscape.md)。
