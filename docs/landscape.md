## 实际提升：Echo 的离线节拍校准

原 Echo 固定以原始输入时间判定，对整体偏早/偏晚的设备与个人习惯没有适配。此次补上的是成熟产品已有的能力，属于本项目的功能提升，**不是校准技术发明**。

- 新增可操作的十二拍校准：四拍热身、八拍采样。参考光圈与可选本地合成提示音，不需要麦克风、网络或任何音频资产。
- 以中位数和中位绝对偏差估计整体偏移，排除明显离群敲击；有效样本不足或节奏离散度过大时，禁止应用建议，保留旧设置。页面明确说明它估计“设备与敲击习惯的整体偏移”，不是硬件精确测量。
- 稳定结果仍需玩家点击应用；可手动调整 `−180…+180 ms` 或归零，异常存储降级为当页可用。设置从下一次演奏生效。
- 引擎对命中、漏拍和结束都采用同一偏移，修复“只调整命中而漏拍仍按旧时间触发”的不一致。光点和声音不被拖动；判定窗口总宽度不变，也不靠放宽评分冒充校准。
- 演奏中禁止修改偏移；切到后台会取消本轮校准，保留旧设置。键盘快捷敲击不吞掉其他按钮、链接或表单的正常空格/Enter 行为。
- 同时修复24帧导演停止试映后状态标签仍写“正在试映”的小问题。

## 验证

`tests/timing.test.cjs` 增加八项有行为意义的测试：稳定采样含一个离群值的估计、样本不足/非数值/不稳定拒绝、偏移限幅、五种正负偏移全曲完美可达且漏拍边界一致、非法偏移拒绝。原十九项故事/网格/剪辑/节奏测试继续执行。

`npm run check` 检查四款均无远程资源、网络 API、ES module、丢失本地文件；`npm run build` 重新生成四份独立 ZIP，根目录有 `index.html`，每份小于20 MiB，附字节数和 SHA-256。校准新增的全部代码与UI仍在 Echo 自己的四个本地文件内，继续可通过 `file://` 打开。独立 ZIP 的 CRC 与根目录结构另用 Python `zipfile` 验证。

浏览器输入、声音启动、触控校准和窄屏表现由主智能体统一 QA。没有宣称自动测试证明所有设备零延迟、活动已提交或现金资格已审核。
